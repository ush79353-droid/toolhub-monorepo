3) Calculation logic
Use these formulas:
Base values
If cost and base margin are known:
- Base Revenue = Cost / (1 - Base Margin/100)
If cost and base markup are known:
- Base Revenue = Cost × (1 + Base Markup/100)
Then derive:
- Base Profit = Base Revenue - Cost
- Base Margin = (Base Revenue - Cost) / Base Revenue × 100
- Base Markup = (Base Revenue - Cost) / Cost × 100
Discounted values
- Price After Discount = Base Revenue × (1 - Discount/100)
- Profit = Price After Discount - Cost
- True Margin = Profit / Price After Discount × 100
- True Markup = Profit / Cost × 100
