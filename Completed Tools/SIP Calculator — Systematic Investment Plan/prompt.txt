## 2) Calculator Purpose
Build a **SIP (Systematic Investment Plan) Calculator** that computes the future value of recurring **monthly investments**.

The calculator should allow the user to enter:

1. **Monthly SIP amount (P)**  
   - Money input
   - Currency selectable

2. **Investment period (t)**  
   - Numeric input
   - Unit: **years**

3. **Expected rate of return (r)**  
   - Percentage input
   - Annual return rate

### Output fields
1. **Total investment**  
   - Total principal invested over the full period

2. **Maturity amount**  
   - Final accumulated future value of SIP

3. **Investment multiplication factor**  
   - `Maturity amount / Total investment`

---

## 3) Formula Requirements

Use the standard SIP future value formula for **monthly contributions**:

- Monthly rate:  
  `i = r / 12 / 100`

- Number of months:  
  `n = t * 12`

- Future value of SIP (ordinary annuity):  
  `FV = P × [((1 + i)^n - 1) / i] × (1 + i)`

Where:
- `P` = monthly SIP amount
- `r` = annual expected return %
- `t` = investment period in years
- `i` = monthly interest rate
- `n` = total number of monthly installments

### Derived values
- **Total investment** = `P × n`
- **Maturity amount** = `FV`
- **Investment multiplication factor** = `FV / Total investment`
